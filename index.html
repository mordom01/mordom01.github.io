Fast NF4 Dequantization Kernels for Large Language Model Inference
2026

NF4 quantization reduces LLM memory footprint 4×, but dequantization back to FP16 creates a throughput bottleneck on current GPUs. We present a lightweight shared memory optimization achieving 2.0–2.2× kernel speedup and up to 1.54× end-to-end improvement — a plug-and-play solution for the HuggingFace ecosystem.

ML Systems CUDA LLM Inference EMC2 @ ASPLOS 2026
X. Qi, C. Jiang, M. Annavaram · arXiv:2604.02556
Icy-Hot: Decoupled Compute Paradigm Towards a General-Purpose Superconducting CPU Design
2026

Proposes a novel granular decoupling of pipeline stages in an SFQ CPU design, exploiting the ultra-fast switching of Josephson Junction logic while managing JJ density constraints. SFQ circuits can be orders of magnitude more energy-efficient than CMOS, making them a strong candidate for post-Moore computing.

Computer Architecture Superconducting Post-CMOS IEEE Trans. Appl. Supercond.
T. Renduchintala, J. Lee, H. Zha, M. Qi, M. Annavaram · IEEE Trans. Appl. Supercond., Mar. 2026
